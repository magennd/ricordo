# User Actions & Setup Guide

Welcome to **Ricordo**! This file contains the straightforward, non-technical steps for you to take whenever you are ready.

---

## Your Code is Pushed! Final 2 Clicks to Activate GitHub Pages

Your code and deployment workflow have successfully pushed to GitHub at `https://github.com/magennd/ricordo`.

GitHub requires you to turn on **GitHub Actions** as the Pages deployment source once:

### Step 1: Switch Pages Source to GitHub Actions
1. Open this link: **[https://github.com/magennd/ricordo/settings/pages](https://github.com/magennd/ricordo/settings/pages)**
2. Under **Build and deployment > Source**, click the dropdown (which currently says *Deploy from a branch*) and select:
   👉 **GitHub Actions**

### Step 2: Verify Workflow Permissions (If Prompted)
1. Open: **[https://github.com/magennd/ricordo/settings/actions](https://github.com/magennd/ricordo/settings/actions)**
2. Scroll down to **Workflow permissions**.
3. Ensure **Read and write permissions** is selected, and click **Save**.

### Step 3: Watch Deployment & Open on Mobile
1. Go to the Actions tab: **[https://github.com/magennd/ricordo/actions](https://github.com/magennd/ricordo/actions)**
2. You will see **Deploy to GitHub Pages** running.
3. Once the green checkmark appears (~45 seconds), your app is live at:
   **[https://magennd.github.io/ricordo/](https://magennd.github.io/ricordo/)**

### Step 4: Install as an App on iPhone
1. Open `https://magennd.github.io/ricordo/` in **Safari** on your iPhone.
2. Tap the **Share** button (the square with an arrow pointing up at the bottom).
3. Tap **Add to Home Screen**, then **Add**.
4. Ricordo will launch in distraction-free full-screen mode like a native app.
